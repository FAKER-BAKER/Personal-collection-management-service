# Сервис управления личными коллекциями

Консольное приложение для систематизации, оценки и ведения учета предметов личных коллекций.

## Возможности
- просмотр списка предметов коллекции с определением редкости;
- добавление новых предметов с валидацией данных;
- поиск предметов по ключевым словам в названии;
- фильтрация по категории предметов;
- сортировка коллекции по оценочной стоимости;
- подсчет суммарной рыночной стоимости всей коллекции;
- удаление предметов по идентификатору;
- сохранение и загрузка данных в формате JSON.

## Структура проекта
- main.py — консольный интерфейс и диспетчеризация команд;
- items.py — функции бизнес-логики;
- storage.py — модуль работы с файлами (JSON);
- utils.py — функции безопасного ввода;
- data/ — каталог с файлами данных (collections.json);
- tests/ — модульные тесты.

## Требования
- Python 3.10+
- pytest >= 8.0
- flake8 >= 7.0

Установка зависимостей:
pip install -r requirements.txt

## Запуск программы
python main.py

## Запуск тестов
pytest

## Проверка качества кода (PEP 8)
flake8
