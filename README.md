# Сервис управления личными коллекциями

## Назначение
Приложение помогает пользователю вести учёт личных коллекций: книг, монет, марок, пластинок и других предметов. Сервис позволяет добавлять предметы в коллекцию, просматривать их, отмечать редкость и оценивать суммарную ценность собрания.

## Целевая аудитория
- Коллекционеры-любители (книги, монеты, марки, винил, комиксы).
- Люди, которые хотят систематизировать домашние коллекции.
- Небольшие клубы коллекционеров.

## Предметная область
Учёт предметов коллекционирования: название, категория, год выпуска, состояние, редкость и оценочная стоимость. Коллекция может состоять из множества предметов, каждый предмет относится к определённой категории.

## Основные сущности
- Пользователь
- Коллекция
- Предмет коллекции
- Категория

## Основные функции
- Добавление нового предмета в коллекцию.
- Просмотр списка предметов коллекции.
- Оценка суммарной стоимости коллекции.
- Проверка редкости предмета по году выпуска.
- Поиск предмета по названию (в перспективе).

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и разграничения доступа;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD.
