# Сервис управления личными коллекциями (Personal Collection Management Service)

## Назначение
Информационная система для учета и каталогизации частных собраний, распределения предметов по категориям и расчета их оценочной стоимости[cite: 137].
Консольная версия приложения (ПР3) дополнена начальным веб-интерфейсом на базе фреймворка Django (ПР5)[cite: 104, 137].

Приложение позволяет:
* Просматривать реестр личных коллекций в веб-браузере[cite: 137];
* Просматривать детальную карточку коллекции с перечнем входящих в нее экспонатов[cite: 137];
* Просматривать единый реестр предметов и экспонатов[cite: 137];
* Просматривать детальную карточку конкретного предмета с автоматическим расчетом редкости («Раритет», «Винтаж», «Современный») и оценкой стоимости[cite: 137];
* Просматривать общую финансовую статистику собрания[cite: 137];
* Сохранять и загружать данные из файлового JSON-хранилища[cite: 137];
* Использовать консольный интерфейс (сохранен с ПР3)[cite: 137].

## Используемые технологии
* **Python 3.10+** — основной язык разработки[cite: 137];
* **Django 5.2 (LTS)** — веб-фреймворк[cite: 109, 137];
* **HTML5 / CSS3 / Bootstrap 5.3** — адаптивная верстка интерфейса страниц[cite: 112, 137];
* **pytest** — набор модульных автоматических тестов[cite: 137];
* **flake8** — статический анализ качества кода и соблюдения PEP 8[cite: 137];
* **mypy** — статическая проверка типов[cite: 137].

## Предметная область
Основными сущностями предметной области выступают[cite: 137]:
* **User (Пользователь)** — владелец личных коллекций[cite: 138];
* **Category (Категория)** — классификатор предметов (монеты, марки, книги и др.);
* **Collection (Коллекция)** — тематическое собрание предметов конкретного пользователя[cite: 138];
* **Item (Экспонат/Предмет)** — объект коллекции, имеющий год выпуска, категорию, сохранность и оценочную стоимость.

## Страницы веб-интерфейса
* `/` — главная страница: описание сервиса и навигация (view-функция `homepage.views.index`)[cite: 138];
* `/collections/` — каталог коллекций пользователя из `data/collections.json` (view-функция `collections_app.views.collections_list`)[cite: 138];
* `/collections/<int:collection_id>/` — страница коллекции со списком предметов (view-функция `collections_app.views.collection_detail`)[cite: 138];
* `/items/` — реестр всех экспонатов из `data/items.json` (view-функция `items_app.views.items_list`)[cite: 138];
* `/items/<int:item_id>/` — карточка экспоната с расчетом редкости (view-функция `items_app.views.item_detail`)[cite: 138].

Если коллекция или предмет с указанным ID не найдены в системе, возвращается статус-код ошибки **404 Not Found** со специальной страницей ошибки[cite: 128, 138].

## Хранение данных
Данные хранятся в JSON-файлах в директории `data/`[cite: 138]:
* `data/users.json`[cite: 138]
* `data/categories.json`
* `data/collections.json`
* `data/items.json`

При загрузке страницы view-функции вызывают методы слоя `storage.py` из ПР3, восстанавливая полноценные Python-объекты со всеми связями (`item.collection`, `col.user`)[cite: 136, 138, 143].
